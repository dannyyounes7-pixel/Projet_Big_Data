## 📂 Contenu du Dépôt

Ce dépôt contient la plateforme Big Data IAR (Indice d'Attractivité Rationnelle) pour l'analyse des communes françaises.

### Documentation Principale

- **README.md** - Vue d'ensemble du projet
- **GUIDE_LANCEMENT_COMPLET.md** - Guide détaillé de lancement (RECOMMANDÉ)
- **QUICKSTART.md** - Guide de démarrage rapide
- **GIT_DEPLOYMENT.md** - Guide de déploiement Git

### Structure du Projet

```
Projet_Big_Data/
├── config/          # Configurations (app, spark, api)
├── src/             # Code source (jobs Spark, utilitaires)
├── api/             # API REST FastAPI
├── viz/             # Dashboard Streamlit
├── scripts/         # Scripts d'exécution
└── docs/            # Documentation technique
```
